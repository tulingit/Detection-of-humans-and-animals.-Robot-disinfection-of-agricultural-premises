## 🎯 О проекте

Учебно-коммерческий проект по детекции человека и животных на основе нейросети YOLO. Разработан в контексте создания **робота-дезинфектора** с функцией навигации и избегания препятствий.

### Назначение

- Детекция людей и животных в реальном времени
- Применение в робототехнике (робот-дезинфектор)
- Обучение и демонстрация технологий компьютерного зрения
- Коммерческое применение в системах безопасности и автоматизации

## 🤖 Связь с робототехникой

### Патент на полезную модель

**Заявка на патент подана** на полезную модель **робота-дезинфектора** с интегрированной системой компьютерного зрения:

- Автоматическая навигация в помещении
- Детекция людей и животных для безопасного перемещения
- Автоматическое избегание препятствий
- Дезинфекция помещений с учётом присутствия живых существ

> ⚖️ **Статус патента**: Заявка подана (Patent Pending)

## 📊 Датасет

### Описание

- **Сбор данных**: Самостоятельный сбор изображений из различных источников
- **Разметка**: Проведена **вручную через CVAT** (Computer Vision Annotation Tool)
- **Качество**: Высококачественная разметка с проверкой
- **Формат**: YOLO format (txt файлы с bounding box)

### Характеристики датасета

| Параметр | Значение |
|----------|----------|
| Инструмент разметки | [CVAT](https://cvat.ai/) |
| Тип сбора | Самостоятельный (кастомный) |
| Разметка | Ручная через CVAT |
| Формат | YOLO |
| Классы | Человек, Собака, Кошка, Другие животные |

## 🤖 Модель

### Архитектура

- **Нейросеть**: YOLO (You Only Look Once)
- **Тип задачи**: Детекция объектов (Object Detection)
- **Фреймворк**: PyTorch
- **Применение**: Робот-дезинфектор, системы безопасности

### Особенности

- Детекция в реальном времени
- Высокая точность локализации
- Оптимизация для встраиваемых систем
- Интеграция с робототехническими платформами
